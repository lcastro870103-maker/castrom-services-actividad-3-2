# CASTROM Services — Actividad 3.2

Sitio estático de autoría propia basado en la propuesta de diseño CASTROM Services.

## Vista previa
Abra `index.html` en su navegador.

## Publicación en Railway
1. Cree un repositorio de GitHub y suba el contenido de esta carpeta (no el ZIP como un único archivo).
2. En Railway, abra el proyecto y seleccione `New` → `GitHub Repo`.
3. Seleccione el repositorio y espere el despliegue Docker.
4. En el servicio, vaya a `Settings` → `Networking` → `Generate Domain`.
5. Si Railway solicita puerto, indique `80`, que es el puerto de Nginx en este proyecto.
6. Abra la URL y compruebe el sitio desde computadora y celular.

Nota: Railway puede descontar consumo del crédito de prueba. No se publica ningún servicio al abrir los archivos localmente.
